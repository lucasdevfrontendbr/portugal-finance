### 🎯 Sobre o Projeto

**PT Portugal Finance** é uma calculadora de salário líquido desenvolvida do zero para resolver um problema real: calcular com precisão quanto um trabalhador em Portugal recebe no final do mês em 2026.

**Por que criei este projeto?**
Estou em transição de carreira para Desenvolvedor Frontend com foco no mercado português. Queria um projeto que mostrasse domínio de JavaScript puro, manipulação de DOM, lógica de cálculo complexa e atenção aos detalhes de UI/UX.

**Principais desafios técnicos resolvidos:**
1. **Lógica Fiscal 2026:** Implementei todas as tabelas de IRS por escalões + cálculo da Segurança Social 11%. O sistema calcula automaticamente subsídio de férias e Natal proporcionais.
2. **Performance:** Zero dependências. 100% Vanilla JS para carregamento instantâneo e controle total do código.
3. **UI Cyberpunk:** Interface responsiva com tema neon, construída com CSS puro. Foco total na experiência do usuário.
4. **Validação de Dados:** Tratamento de inputs, formatação de moeda em EUR e prevenção de erros de cálculo.

**O que este projeto demonstra para recrutadores:**
- **Fundamentos Sólidos:** Domínio de HTML, CSS e JavaScript sem frameworks. Sei a base.
- **Resolução de Problemas:** Peguei regras fiscais complexas e transformei em código funcional.
- **Atenção a Detalhes:** Pesquisa real das tabelas de IRS 2026 de Portugal para entregar um produto útil.
- **Deploy Moderno:** Publicado na Vercel com domínio próprio e versionamento no GitHub.

**Próximos passos:**
Planejo adicionar modo escuro/claro, cálculo para trabalhadores independentes e exportar PDF do resultado.

**Objetivo Profissional:**
Busco minha primeira oportunidade como Desenvolvedor Frontend Júnior/Estágio Remoto para Portugal. Tenho disponibilidade imediata e português nativo.

**Comunicação:** Me comunico bem em português. Em inglês, consigo me virar no básico do dia a dia com apoio de ferramentas como Google Tradutor. Não tenho leitura fluente de documentação técnica ainda, mas estou estudando diariamente para evoluir. Não prometo o que não entrego.

Muita vontade de aprender com um time sênior e agregar com código limpo e comprometimento.
